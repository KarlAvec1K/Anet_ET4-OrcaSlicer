# Anet ET4 Klipper profile for Cura

This profile targets the Anet ET4 with a 0.4 mm nozzle, dual-drive Bowden extruder, Klipper and a 220 x 220 x 250 mm build volume.

Copy the two `.cfg` files into the matching folders under `%APPDATA%\cura\5.10` and copy the `.fdm_material` files into `%APPDATA%\cura\5.10\materials`. Restart Cura, select `Anet ET4 - Klipper`, then select `ET4 PLA By Codex` or `ET4 Silk PLA By Codex`.

`Anet_ET4_By_Codex_Production.curaprofile` is the importable Cura quality profile for the 0.20 mm production setup. Import it from Cura's profile manager after selecting `Anet ET4 - Klipper`.
